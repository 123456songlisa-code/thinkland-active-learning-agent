# MVP 用户测试与评测计划

## 研究问题

1. 儿童能否理解“把知识讲给别人”的任务？
2. 诊断是否能正确区分已覆盖、遗漏和误解？
3. 分级帮助能否减少直接查看完整答案的行为？
4. 儿童是否能在延时复习中以更少提示提取知识？
5. 家长能否从报告中理解孩子的学习过程？

## 建议样本

- 探索性测试：3 名 9-12 岁儿童；
- 可用性测试：5-8 名 9-12 岁儿童；
- 专家校验：2 名小学教师或教育相关人员；
- 家长访谈：5 名家长。

所有儿童测试均需监护人知情同意，不收集真实姓名、学校、联系方式等非必要信息。

## 测试任务

1. 选择一篇材料并完成阅读；
2. 脱离材料进行首次讲述；
3. 阅读诊断并解释自己下一步要补什么；
4. 最多使用四级帮助完成局部修正；
5. 把薄弱概念加入复习岛；
6. 24-48 小时后重新完成主动提取；
7. 家长阅读成长报告并复述其理解。

## 记录指标

- 任务完成率；
- 首次讲述字数和知识点覆盖率；
- 诊断人工一致率；
- 儿童理解诊断结果的比例；
- 平均最高提示等级；
- 首次与延时复习的覆盖率变化；
- 无提示提取率；
- 单次任务耗时；
- 儿童主观压力（5级表情量表）；
- 家长对报告可理解性的评分。

## 简历数据使用原则

只有完成测试并保留匿名原始记录后，才能把样本数、完成率、覆盖率变化和提示依赖变化写入简历。开发阶段不预设提升数字。
