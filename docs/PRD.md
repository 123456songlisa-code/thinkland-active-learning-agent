# 启思岛 ThinkLand 产品需求文档

## 1. 文档信息

- 产品版本：MVP 0.1
- 产品定位：面向 9-12 岁儿童的主动学习 Agent
- 核心目标：用“主动讲述—理解诊断—分级帮助—延时复习”代替单向知识输入
- 当前形态：响应式 Web 应用

## 2. 问题与机会

儿童使用通用问答 AI 时，系统通常以更快、更完整地给出答案为目标。这会缩短解题路径，却可能跳过主动提取、组织语言、暴露缺口和修正理解等学习环节。

ThinkLand 不以“立即答对”为首要目标，而以“儿童能否脱离材料重新组织知识”为核心判断。系统扮演见习老师的学生与学习导师：先邀请儿童讲述，再诊断已覆盖、遗漏和可能的误解，最后用最小必要帮助促进儿童自己补全。

## 3. 目标用户

### 儿童用户

- 9-12 岁，能够完成基础文字阅读与输入；
- 阅读时觉得“看懂了”，合上材料后难以完整讲述；
- 容易在遇到困难时直接查看答案；
- 需要低压力、短周期、可感知的成长反馈。

### 家长用户

- 关心孩子是否真正理解，而不只关心题目正确率；
- 希望获得可解释的学习报告与陪伴建议；
- 不希望 AI 替代孩子思考或输出不适龄内容。

## 4. MVP范围

### 必须实现

1. 三篇结构化适龄学习材料；
2. 见习老师任务与主动复述输入；
3. 知识点覆盖、部分覆盖、遗漏诊断；
4. 典型误解识别；
5. 四级帮助：轻提示、关键词、局部笔记、导师示范；
6. 提示依赖度记录；
7. 弱项生成复习卡；
8. 学习记录与家长成长报告；
9. 可选大模型生成儿童友好的个性化反馈；
10. 无模型时可演示、可测试的本地诊断引擎。

### 暂不实现

- 账号与跨设备同步；
- 语音识别和语音播报；
- 教师批量布置任务；
- 自动生成任意学科材料；
- 排行榜、公开社交和儿童间私信；
- 自动购买或付费体系。

## 5. 核心用户流程

1. 儿童选择学习材料并阅读；
2. 系统隐藏直接答案导向，引导儿童脱离材料讲述；
3. 诊断引擎将讲述与结构化知识点对照；
4. 系统展示已覆盖、部分覆盖、待补充与可能误解；
5. 每次只选择一个优先缺口，通过问题引导；
6. 儿童按需请求更高级别帮助并重新讲述；
7. 系统记录提示依赖度，把薄弱概念加入复习岛；
8. 在 24-48 小时后重新发起主动提取；
9. 家长查看学习次数、覆盖率、提示等级与薄弱概念。

## 6. 诊断逻辑

每篇材料由多个 `concept` 构成，每个概念包含关键词、最低覆盖条件、简要说明、诊断问题和四级提示。MVP 先用可解释匹配引擎判断知识点覆盖，并用误解规则检测典型错误。

配置模型后，Agent只负责把确定性诊断转化成更自然的反馈和追问。模型不能修改知识点覆盖结论，也不能执行高风险动作；调用超时或输出异常时立即降级到本地引擎。

## 7. 核心指标

### 北极星指标

儿童在不查看完整答案的情况下，经分级帮助后主动补全关键概念的比例。

### 过程指标

- 首次主动讲述完成率；
- 知识点覆盖率；
- 平均提示等级；
- 使用完整示范的会话占比；
- 复习卡按时完成率；
- 延时复习后的无提示提取率；
- 单次会话完成时长；
- 诊断结果人工一致率；
- API成功率和P95响应时间。

### 护栏指标

- 直接泄露完整答案率；
- 负面或不适龄表达率；
- 事实性错误率；
- 因调用失败导致的任务中断率。

## 8. 验收标准

- 三篇材料均可完成完整闭环；
- 对完整和明显不完整讲述的诊断符合预设知识点；
- 第一轮帮助不得包含完整示范；
- 只有儿童主动点击后才逐级增加帮助；
- 模型不可用时核心流程仍然可用；
- 复习卡和学习记录保存在浏览器本地；
- 桌面端与移动端关键任务均可完成；
- 自动化测试全部通过。
